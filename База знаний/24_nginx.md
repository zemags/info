#### nginx
- главный процесс — чтение и проверка конфига, управление рабочими процессами
- рабочие процессы — обрабатывают запросы, количество может быть задано в конфиге или автоматически по числу доступных ядер
- конфиг обычно находится в `/usr/local/nginx/conf`, `/etc/nginx` или `/usr/local/etc/nginx`

#### структура конфига
- простая директива — имя и параметр через пробел, точка с запятой `;` в конце
- блочная директива — вместо точки с запятой набор дополнительных инструкций внутри `{}`, внутри скобок можно задать другие директивы
- после `#` идет комментарий

#### управление nginx
##### быстрое завершение
```
nginx -s stop
```
##### плавное завершение
```
nginx -s quit
```
##### перезагрузка конфигурационного файла
```
nginx -s reload
```
##### переоткрытие лог-файлов
```
nginx -s reopen
```
##### список всех запущенных процессов nginx
```
ps -ax | grep nginx
```

#### пример конфига для статических файлов
```
server {
    # '/' — короткий префикс
    location / {
        # статика из /data/www, запрос http://localhost/some/example.html вернет /data/www/some/example.html
        root /data/www;
    }
    # '/images/' — длинный префикс, поиск сначала идет по длинным префиксам
    location /images/ {
        root /data;
    }
}
```

#### пример конфига прокси-сервера
Типичный случай: принял запрос, отправил на один из проксируемых серверов, получил ответ, отдал клиенту
```
server {
    location / {
        proxy_pass http://localhost:8080/;
    }

    # запросы на изображения с расширениями gif, jpg, png обрабатываются здесь
    location ~ \.(gif|jpg|png)$ {
        root /data/images;
    }
}
```
